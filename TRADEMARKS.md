# Trademark policy

The code is under the [Business Source License 1.1](LICENSE), which gives no rights in the Candydati name or logo
("the marks"). This policy says how you may use them. It covers the marks, not the code: what you may do with the code is
in the license.

The marks belong to Fabrizio Lallo. The goal is simple: people must be able to tell the official Candydati apart from
a version someone else changed or runs.

## Allowed without asking

- **Run it unchanged under its name.** If you self-host an unmodified release, it can keep showing "Candydati".
- **Run a modified version for your own hiring**, for your clients' searches if you are an agency, or for the single
  organization you install and host it for as a consultant, while it is not offered to the public as a product. It
  may keep the default name it shows.
- **Say what it is.** Write in plain text that your software or service "is based on Candydati", "uses Candydati" or
  "is a fork of Candydati", as long as nobody could take it for the official project or think it is endorsed by it.
- **Talk about it.** Articles, talks, tutorials, comparisons and reviews can name the project and link to it.
- **Contribute.** Pull requests, issues and community packages can name the project.

## Not allowed without written permission

- **Naming something else Candydati.** A fork, a distribution, a hosted service, a company, a domain or an app store
  listing can't be called Candydati or a name that is confusingly similar (for example "Candydati Pro" or
  "Candydati Cloud").
- **Publishing a modified version under the marks.** If you distribute a changed version, or make one available to
  anyone beyond the cases above, give it your own name and logo: set `PLATFORM_NAME`,
  `NUXT_PUBLIC_PLATFORM_NAME` and `NUXT_PUBLIC_PLATFORM_ICON_URL` (see [docs/ENVIRONMENT.md](docs/ENVIRONMENT.md)).
- **Suggesting a relationship that doesn't exist.** No "official", "certified", "partner" or "endorsed by Candydati"
  without written agreement.
- **Using the logo** outside an unmodified release, except for linking to the project.
